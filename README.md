# SportVerse

SportVerse es un proyecto frontend de ecommerce dedicado a la venta de productos deportivos, con foco actual en camisetas de fútbol. Incluye una página de inicio y secciones para explorar la tienda, consultar el carrito, leer el blog, conocer el proyecto y contactar.

## Tecnologías

- HTML5
- CSS3
- JavaScript (previsto)

## Estructura

```text
sportverse-ecommerce/
├── index.html
├── styles.css
├── pages/
│   ├── tienda.html
│   ├── carrito.html
│   ├── blogs.html
│   ├── acercaDe.html
│   └── contacto.html
├── img/
└── prisma/
    └── Prisma.ttf
```

## Características

- Página de inicio con navegación, hero promocional y banner de ofertas.
- Menú de navegación adaptable a pantallas pequeñas.
- Páginas separadas para tienda, carrito, blog, información y contacto.
- Estilos y recursos visuales organizados en archivos y carpetas del proyecto.
- Proyecto de frontend; la interactividad con JavaScript está prevista.

## Secciones

| Sección | Descripción |
| --- | --- |
| Inicio | Presentación de la tienda, promoción de camisetas retro y ofertas. |
| Tienda | Página destinada al catálogo de productos. |
| Carrito | Página destinada al carrito de compras. |
| Blog | Sección para publicaciones relacionadas con el proyecto. |
| Acerca de | Información sobre SportVerse. |
| Contacto | Formulario y datos de contacto. |
